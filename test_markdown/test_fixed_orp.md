# Fixed ORP Test

This is a test to demonstrate the fixed-position ORP highlighting feature. 

The Optimal Recognition Point should now stay in the same visual location while the rest of the characters move around it.

Test words of different lengths:
- cat
- quick
- reading
- understanding
- implementation
- a
- of
- speedreading
- technology

Words with punctuation:
- Hello!
- Wait...
- Really?
- Yes.
- No;
- Stop:

The highlighted character should remain fixed at the center focal point, making it easier to maintain focus during speed reading sessions.
