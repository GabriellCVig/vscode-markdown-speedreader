# Change Log

All notable changes to the "markdownspeedreader" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.0]

Initial release.

- Speed reading (RSVP) for markdown and text files at 50–1000 WPM, with Optimal Recognition Point (ORP) highlighting.
- Dedicated code panel: fenced code blocks and long inline code are shown alongside the reading area; short inline code stays inline with monospace styling.
- Mermaid diagrams render as live SVG in the code panel, with an optional `speedreader.autoPauseOnDiagram` setting to pause playback on a diagram.
- Play/pause/stop via buttons and keyboard (Space, Escape), click-to-seek progress bar, configurable WPM, ORP color, and pause-on-punctuation.
